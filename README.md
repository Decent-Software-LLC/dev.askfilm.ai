# dev.askfilm.ai

Development environment for evaluating Qwen2.5-VL video understanding against AskFilm basketball footage.

The static site is published with GitHub Pages at `https://dev.askfilm.ai`. Model inference must run through a server-side service; API credentials must never be added to this repository or browser code.

## Evaluation target

- Timestamped basketball events
- Strict JSON source data
- Markdown review report
- Interactive video anchors
- Accuracy, latency, and cost comparison
